## 当前问题

大部分测试失败是因为返回401而不是200/403，主要原因：
1. **JWT Token验证失败** - admin_headers fixture可能没有正确设置token
2. **Redis Token验证** - 单点登录检查可能失败
3. **@admin_required装饰器** - 可能在@jwt_required之前执行

## 修复计划

## 独立测试脚本

创建`test_admin_simple.py`简化测试：

```python
"""简化的管理员测试"""
import pytest
from app import create_app
from app.extensions import db
from app.models import User
from flask_jwt_extended import create_access_token


def test_admin_api_basic():
    """基础API测试"""
    app = create_app()
    app.config['TESTING'] = True
    app.config['SQLALCHEMY_DATABASE_URI'] = 'sqlite:///:memory:'

    with app.app_context():
        db.create_all()

        # 创建管理员
        admin = User(
            email='admin@test.com',
            password_hash='hash',
            role='admin',
            level=5
        )
        db.session.add(admin)
        db.session.commit()

        # 创建token
        token = create_access_token(identity=admin.id)

        # 测试API
        client = app.test_client()
        response = client.get(
            '/api/admin/stats/overview',
            headers={'Authorization': f'Bearer {token}'}
        )

        print(f"Status: {response.status_code}")
        print(f"Data: {response.get_json()}")

        db.drop_all()


if __name__ == '__main__':
    test_admin_api_basic()
```

## 临时解决方案

如果需要快速验证功能，可以暂时禁用单点登录检查：

在`app/utils/decorators.py`中的`admin_required`装饰器：
```python
def admin_required(f):
    @wraps(f)
    def decorated_function(*args, **kwargs):
        user_id = get_jwt_identity()
        user = User.query.get(user_id)

        if not user or user.role != 'admin':
            return jsonify({"code": 403, "msg": "Admin permission required"}), 403

        return f(*args, **kwargs)
    return decorated_function
```

**注意**：这只是测试用，生产环境必须启用完整的安全检查！
