## 数据库依赖

### 使用的表
1. **users** - 用户表
   - 字段：`id`, `created_at`
   - 用途：统计新增用户

2. **tasks** - 任务表
   - 字段：`cost_points`, `status`, `created_at`
   - 用途：统计积分消耗和活跃任务

3. **transactions** - 交易表
   - 字段：`type`, `amount`, `created_at`
   - 用途：统计CDK充值

## 注意事项

1. **时区处理**：所有时间使用 UTC，前端需要转换为本地时区
2. **空数据处理**：没有数据的日期会填充0，不会缺失数据点
3. **权限控制**：必须是管理员角色（`role='admin'`）才能访问
4. **数据精度**：积分使用 `Decimal(10,2)`，返回时转为 float
