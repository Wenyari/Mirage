# 管理员仪表盘测试运行指南

## 前置条件

### 1. 确保Redis已启动
```bash
# Windows系统
redis-server

# 或者作为服务运行
# 打开服务管理器 (services.msc)，启动 Redis 服务
```

### 2. 确保依赖已安装
```bash
conda activate sora_env
pip install pytest pytest-cov
```

## 测试命令

### 方式一：运行单个测试文件

```bash
# 进入项目目录
cd F:\Mirage\backend

# 激活虚拟环境并运行测试
conda run -n sora_env pytest tests/test_api/test_admin_dashboard.py -v
```

### 方式二：运行特定测试类

```bash
# 只测试核心指标接口
conda run -n sora_env pytest tests/test_api/test_admin_dashboard.py::TestDashboardOverview -v

# 只测试趋势图接口
conda run -n sora_env pytest tests/test_api/test_admin_dashboard.py::TestDashboardChart -v

# 只测试数据准确性
conda run -n sora_env pytest tests/test_api/test_admin_dashboard.py::TestDashboardDataAccuracy -v
```

### 方式三：运行特定测试函数

```bash
# 测试获取核心指标成功的场景
conda run -n sora_env pytest tests/test_api/test_admin_dashboard.py::TestDashboardOverview::test_get_overview_success -v

# 测试权限验证
conda run -n sora_env pytest tests/test_api/test_admin_dashboard.py::TestDashboardOverview::test_get_overview_unauthorized -v
```

### 方式四：生成测试覆盖率报告

```bash
# 运行测试并生成覆盖率报告
conda run -n sora_env pytest tests/test_api/test_admin_dashboard.py --cov=app.services.admin --cov=app.api.admin --cov-report=html --cov-report=term-missing -v

# 覆盖率报告会生成在 htmlcov/index.html
# 用浏览器打开查看详细覆盖率
```

### 方式五：显示详细输出

```bash
# 显示print语句输出
conda run -n sora_env pytest tests/test_api/test_admin_dashboard.py -v -s

# 显示测试失败时的详细信息
conda run -n sora_env pytest tests/test_api/test_admin_dashboard.py -v --tb=long
```

## 常见问题排查

### 问题1: Redis连接失败
```
redis.exceptions.ConnectionError: Error connecting to Redis
```

**解决方案**：
1. 检查Redis服务是否启动
2. 检查 `.env` 文件中的 `REDIS_URL` 配置
3. 测试使用的是Redis数据库15（见conftest.py:26）

### 问题2: 数据库错误
```
sqlalchemy.exc.OperationalError
```

**解决方案**：
- 测试使用内存数据库（SQLite），无需配置
- 如果仍有问题，检查 `app/models` 是否正确导入

### 问题3: JWT相关错误
```
RuntimeError: Working outside of application context
```

**解决方案**：
- 确保使用了正确的fixtures（`client`, `admin_headers`）
- 不要直接调用 `create_access_token`，使用fixture提供的headers

### 问题4: 导入错误
```
ImportError: cannot import name 'xxx'
```

**解决方案**：
```bash
# 确保在虚拟环境中
conda activate sora_env

# 重新安装项目依赖
pip install -e .
```

## 调试技巧

### 1. 在测试中添加断点
```python
def test_get_overview_success(self, client, admin_headers, db_session):
    response = client.get('/api/admin/stats/overview', headers=admin_headers)

    import pdb; pdb.set_trace()  # 添加断点

    assert response.status_code == 200
```

运行测试时会在断点处暂停，可以交互式调试。

### 2. 查看测试数据
```python
def test_get_overview_success(self, client, admin_headers, db_session):
    # ... 创建测试数据 ...

    # 打印数据库中的实际数据
    print(f"Users count: {User.query.count()}")
    print(f"Tasks count: {Task.query.count()}")

    response = client.get('/api/admin/stats/overview', headers=admin_headers)
```

使用 `-s` 参数运行测试查看输出。

### 3. 只运行失败的测试
```bash
# 首次运行
conda run -n sora_env pytest tests/test_api/test_admin_dashboard.py -v

# 只重新运行失败的测试
conda run -n sora_env pytest tests/test_api/test_admin_dashboard.py -v --lf
```

## 集成到CI/CD

如果使用GitHub Actions：

```yaml
# .github/workflows/test.yml
name: Run Tests

on: [push, pull_request]

jobs:
  test:
    runs-on: ubuntu-latest

    steps:
      - uses: actions/checkout@v2

      - name: Setup Redis
        uses: supercharge/redis-github-action@1.4.0

      - name: Setup Conda
        uses: conda-incubator/setup-miniconda@v2
        with:
          activate-environment: sora_env
          environment-file: environment.yml

      - name: Run Tests
        run: |
          conda activate sora_env
          pytest tests/test_api/test_admin_dashboard.py -v --cov --cov-report=xml

      - name: Upload Coverage
        uses: codecov/codecov-action@v2
```
