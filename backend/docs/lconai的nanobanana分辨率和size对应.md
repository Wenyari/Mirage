# Gemini（Nano Banana）

本站支持Nano Banana模型支持原生接口和OpenAI接口（通用接口），建议使用通用接口，可以通用使用更多模型，创建图片、图片编辑可使用同一个创建图片接口（/v1/images/generations），同时也支持谷歌原生接口，API地址和密钥更换我们的就可以。
