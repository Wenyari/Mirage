# GoGen AIGC 资产采集系统技术方案

## 1. 项目背景与目标

构建一套自动化的数据采集系统，从目标 AIGC 社区（如 Nanobanana/Sora2）采集高质量的 **提示词（Prompts）** 和 **媒体资源（图片/视频）**。
系统需支持中英文提示词区分、视频/图片分类、自动化转存 Cloudflare R2 对象存储，并最终通过安全的方式将元数据导入生产环境数据库。

## 2. 系统架构设计

系统采用 **"本地重、云端轻"** 的架构，将高耗能的网络请求和媒体处理放在本地开发机，云端仅负责存储和元数据写入。

## 3. 数据库设计 (MySQL)

根据需求，去除了平台字段，增加了中英文提示词区分及视觉元数据。

```sql
CREATE TABLE `ai_media_assets` (
  `id` BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  
  -- 核心分类
  `media_type` ENUM('image', 'video') NOT NULL DEFAULT 'image' COMMENT '资源类型',
  
  -- 提示词部分
  `prompt_en` TEXT COMMENT '英文提示词 (原始)',
  `prompt_zh` TEXT COMMENT '中文提示词 (翻译或原始)',
  `negative_prompt` TEXT COMMENT '负向提示词',
  
  -- 视觉元数据 (用于前端瀑布流完美展示)
  `width` INT UNSIGNED DEFAULT 0 COMMENT '宽度 (px)',
  `height` INT UNSIGNED DEFAULT 0 COMMENT '高度 (px)',
  `aspect_ratio` DECIMAL(4, 2) DEFAULT 1.0 COMMENT '宽高比',
  
  -- 存储路径
  `r2_key` VARCHAR(255) NOT NULL COMMENT '主资源 R2 Key',
  `r2_url` VARCHAR(512) NOT NULL COMMENT '主资源 CDN 链接',
  `cover_r2_key` VARCHAR(255) COMMENT '封面/缩略图 R2 Key (视频必填)',
  `cover_r2_url` VARCHAR(512) COMMENT '封面/缩略图 CDN 链接',
  
  -- 模型参数 (扩展用)
  `model_params` JSON COMMENT '包含 seed, sampler, cfg_scale, steps 等',
  
  -- 索引与去重
  `source_id` VARCHAR(128) NOT NULL COMMENT '源站资源ID (用于去重)',
  `created_at` TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_source_id` (`source_id`), -- 核心去重索引
  KEY `idx_media_type` (`media_type`),
  KEY `idx_created_at` (`created_at`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='AIGC资产库';

```

## 4. 核心模块详细设计

### 4.1 爬虫模块 (Local)

* **技术栈**: `Python 3.10+`, `httpx` (高并发请求), `Playwright` (如果目标站有强反爬或动态渲染), `boto3` (R2交互).
* **功能**:
1. 遍历目标网站列表页。
2. 解析详情页，提取 Prompt (区分中英文，若无中文留空或调用翻译 API)。
3. 提取视频/图片的原始下载链接。



### 4.2 媒体处理与上传模块 (关键)

为了获取宽高和生成视频封面，**不能单纯使用流式转发**，建议采用“小文件内存处理，大文件临时文件”策略。

* **图片处理流程**:
1. 下载图片二进制数据到内存 (`io.BytesIO`).
2. 使用 `Pillow` 打开，获取 `width`, `height`。
3. 计算 `aspect_ratio`。
4. 调用 `boto3` 上传内存数据到 R2。
5. 返回 R2 URL 和 尺寸信息。


* **视频处理流程**:
1. 下载视频流保存为本地临时文件 (`temp_video.mp4`).
2. 使用 `ffmpeg-python` 读取元数据 (宽、高、时长)。
3. 截取第一帧或指定帧作为封面图片 (`cover.jpg`)。
4. 上传视频文件和封面图片到 R2。
5. 删除本地临时文件。



### 4.3 数据同步模块

* **格式**: JSON 数组。
```json
[
  {
    "source_id": "829312",
    "media_type": "video",
    "prompt_en": "A futuristic city...",
    "prompt_zh": "未来城市...",
    "width": 1920,
    "height": 1080,
    "r2_key": "videos/829312.mp4",
    "r2_url": "https://assets.gogen.com/videos/829312.mp4",
    "cover_r2_url": "https://assets.gogen.com/covers/829312.jpg"
  }
]

```


* **传输**: 使用 `subprocess` 调用系统 `scp` 命令。

## 6. 注意事项与优化

1. **翻译策略**:
* 如果源站只有英文，建议在本地爬虫阶段集成 `googletrans` 库或调用 DeepL API 生成 `prompt_zh`，这样入库时数据就是完整的。


2. **反爬虫风控**:
* 在 `httpx` 请求头中务必添加 `User-Agent`。
* 设置随机休眠 (`time.sleep(random.uniform(1, 3))`) 防止被封 IP。


3. **文件名规范**:
* 上传 R2 时，建议路径规范化：
* 图片: `images/{yyyyMM}/{uuid}.png`
* 视频: `videos/{yyyyMM}/{uuid}.mp4`
* 封面: `covers/{yyyyMM}/{uuid}.jpg`


* 按年月分文件夹有助于未来管理海量文件。
