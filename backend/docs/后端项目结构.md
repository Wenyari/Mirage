这是一个为您量身定制的 Python + Flask 项目结构。

考虑到您是 **2 人团队**，这个结构遵循 **“模块化单体 (Modular Monolith)”** 原则：

1. **扁平化**：不搞过度复杂的微服务。
2. **职责分离**：API 路由（Controller）、业务逻辑（Service）、数据模型（Model）分层，避免代码全部堆在 `app.py` 里。
3. **异步友好**：专门划分了 `worker` 目录用于处理 Sora 等耗时任务。

### 🔑 关键文件代码示例
为了让您快速上手，我给出了几个核心文件的代码骨架。

#### 1. `app/extensions.py` (插件统一管理)
防止循环引用，所有插件在这里实例化。

```python
from flask_sqlalchemy import SQLAlchemy
from flask_jwt_extended import JWTManager
from flask_redis import FlaskRedis
from flask_cors import CORS
from flask_migrate import Migrate

# 初始化但不绑定 App
db = SQLAlchemy()
jwt = JWTManager()
redis_client = FlaskRedis()
cors = CORS()
migrate = Migrate()

```

#### 2. `app/__init__.py` (工厂模式)
这是 Flask 的心脏。

```python
from flask import Flask
from app.config import Config
from app.extensions import db, jwt, redis_client, cors, migrate
from app.api import register_blueprints

def create_app(config_class=Config):
    app = Flask(__name__)
    app.config.from_object(config_class)

    # 1. 初始化插件
    db.init_app(app)
    jwt.init_app(app)
    redis_client.init_app(app)
    cors.init_app(app) # 允许跨域
    migrate.init_app(app, db)

    # 2. 注册路由蓝图
    register_blueprints(app)

    return app

```

#### 3. `app/models/user.py` (表结构定义)
对应之前设计的数据库表。

```python
from app.extensions import db
from datetime import datetime

class User(db.Model):
    __tablename__ = 'users'

    id = db.Column(db.Integer, primary_key=True)
    email = db.Column(db.String(100), unique=True, nullable=False)

    level = db.Column(db.SmallInteger, default=1) # T1-T5
    
    # 关系映射 (可选)

        return f'<User {self.email}>'

```

#### 4. `app/api/tasks.py` (路由示例)
Controller 层，只负责接收参数和返回结果，逻辑丢给 Service。

```python
from flask import Blueprint, request, jsonify
from flask_jwt_extended import jwt_required, get_jwt_identity
from app.services.task_service import submit_sora_task
from app.utils.decorators import check_single_session

bp = Blueprint('tasks', __name__, url_prefix='/api/tasks')

@bp.route('', methods=['POST'])
@jwt_required()
@check_single_session # 单点登录互斥检查
def create_task():
    user_id = get_jwt_identity()
    data = request.json
    
    try:
        # 调用业务层：包含并发检查、预扣费、入队
        task_id = submit_sora_task(user_id, data)
        return jsonify({"code": 200, "data": {"task_id": task_id}})
    except ValueError as e:
        return jsonify({"code": 400, "msg": str(e)}), 400

```

#### 5. `run.py` (API 启动入口)
生产环境使用 Gunicorn 运行此文件：`gunicorn -w 4 run:app`

```python
from app import create_app

app = create_app()

if __name__ == '__main__':
    app.run(host='0.0.0.0', port=5000, debug=True)

```

#### 6. `worker.py` (异步 Worker 入口)
这是跑在后台的“苦力”。

```python
import redis
from rq import Worker, Queue, Connection
from app import create_app
from app.config import Config

# 需要加载 App 上下文，否则无法读取 DB
app = create_app()

listen = ['high_priority', 'default'] # 监听的队列列表

if __name__ == '__main__':
    with app.app_context():
        with Connection(redis.from_url(Config.REDIS_URL)):
            worker = Worker(map(Queue, listen))
            worker.work()

```

### 💡 给开发者的建议
1. **从 Models 开始写**：先把 `app/models/` 下的几个文件建好，运行 `flask db migrate` 和 `flask db upgrade`，把数据库表建起来。
2. **Service 层是重点**：
+ 不要在 `api/` 路由里写 `db.session.add()`。
+ 去 `services/pay_service.py` 里写一个 `deduct_balance(user_id, amount)` 函数，这样以后其他地方要扣费也能复用。



3. **调试 Worker**：
+ 开发时，开两个终端。
+ 终端 1: `python run.py` (跑 API)
+ 终端 2: `python worker.py` (跑任务处理)



这个结构足够清晰，2 个人分工时，一个人负责写 `api/` 和 `frontend` 对接，另一个人负责 `services/` 和 `worker/` 的后台逻辑，互不冲突。
