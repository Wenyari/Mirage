# 管理员模块结构说明

## 目录结构

```
backend/
├── app/
│   ├── api/
│   │   └── admin/                    # 管理员API模块
│   │       ├── __init__.py           # 主蓝图注册
│   │       ├── dashboard.py          # 仪表盘接口
│   │       ├── cdk.py                # CDK管理接口（待实现）
│   │       ├── users.py              # 用户管理接口（待实现）
│   │       └── ...                   # 其他管理接口
│   ├── services/
│   │   └── admin/                    # 管理员服务层
│   │       ├── __init__.py           # 服务导出
│   │       ├── dashboard_service.py  # 仪表盘数据服务
│   │       ├── cdk_service.py        # CDK服务（待实现）
│   │       └── ...                   # 其他服务
```

## 设计原则

### 1. 模块化设计
- 每个功能模块独立一个文件
- 避免单个文件过长（建议不超过300行）
- 便于团队协作和代码维护

### 2. 分层架构
- **API层** (`app/api/admin/`): 处理HTTP请求、参数验证、权限检查
- **服务层** (`app/services/admin/`): 业务逻辑、数据库查询
- **模型层** (`app/models/`): 数据模型定义

### 3. 统一路由前缀
- 所有管理员接口统一使用 `/api/admin` 前缀
- 子模块路由自动继承父级前缀

## 已实现功能

### 仪表盘接口

#### 1. 获取核心指标
```http
GET /api/admin/stats/overview
Authorization: Bearer <admin_token>
```

**响应示例**：
```json
{
  "code": 0,
  "message": "Success",
  "data": {
    "today_new_users": 42,
    "today_points_consumed": 12500.50,
    "today_cdk_recharge": 50000.00,
    "active_tasks": 18
  }
}
```

#### 2. 获取趋势图数据
```http
GET /api/admin/stats/chart?days=7
Authorization: Bearer <admin_token>
```

**请求参数**：
- `days` (可选): "7" 或 "30"，默认 "7"

**响应示例**：
```json
{
  "code": 0,
  "message": "Success",
  "data": [
    {
      "date": "2024-12-24",
      "new_users": 35,
      "points_consumed": 9800.50,
      "cdk_recharge": 28000.00
    },
    ...
  ]
}
```

### 步骤1: 创建服务层文件

在 `app/services/admin/` 创建新的服务文件，例如 `cdk_service.py`:

```python
"""
CDK管理服务
"""
from app.extensions import db
from app.models import CDK

def generate_cdk_batch(points, count, batch_no=None):
    """批量生成CDK"""
    # 业务逻辑
    pass
```

### 步骤2: 导出服务

在 `app/services/admin/__init__.py` 中添加导出：

```python
from .cdk_service import generate_cdk_batch

__all__ = [
    'get_dashboard_overview',
    'get_trend_chart_data',
    'generate_cdk_batch',  # 新增
]
```

### 步骤3: 创建API路由文件

在 `app/api/admin/` 创建新的路由文件，例如 `cdk.py`:

```python
"""
CDK管理 API 路由
"""
from flask import Blueprint, request, jsonify
from flask_jwt_extended import jwt_required
from app.utils.decorators import admin_required
from app.services.admin import generate_cdk_batch

bp = Blueprint('admin_cdk', __name__)

@bp.route('/cdk/generate', methods=['POST'])
@jwt_required()
@admin_required
def generate():
    """生成CDK"""
    # 处理请求
    pass
```

### 步骤4: 注册蓝图

在 `app/api/admin/__init__.py` 中注册新蓝图：

```python
from .dashboard import bp as dashboard_bp
from .cdk import bp as cdk_bp  # 新增

admin_bp = Blueprint('admin', __name__, url_prefix='/api/admin')

admin_bp.register_blueprint(dashboard_bp)
admin_bp.register_blueprint(cdk_bp)  # 新增
```

### 步骤5: 编写测试

在 `tests/test_api/` 创建测试文件 `test_admin_cdk.py`。

## 权限验证

所有管理员接口都需要两个装饰器：

```python
@login_required      # JWT身份验证
@admin_required      # 管理员权限验证
```

装饰器定义在 `app/utils/decorators.py`。

## 前端对接指南

### 基础配置

```typescript
// api/admin.ts
import axios from 'axios';

const API_BASE = '/api/admin';

// 获取仪表盘核心指标
export async function getOverview() {
  return axios.get(`${API_BASE}/stats/overview`);
}

// 获取趋势图数据
export async function getChartData(days: '7' | '30' = '7') {
  return axios.get(`${API_BASE}/stats/chart`, {
    params: { days }
  });
}
```

### 数据类型定义

```typescript
// types/admin.ts

// 核心指标
export interface DashboardOverview {
  today_new_users: number;
  today_points_consumed: number;
  today_cdk_recharge: number;
  active_tasks: number;
}

// 趋势图数据点
export interface ChartDataPoint {
  date: string;
  new_users: number;
  points_consumed: number;
  cdk_recharge: number;
}
```

### 组件使用示例

```vue
<script setup lang="ts">
import { ref, onMounted } from 'vue';
import { getOverview, getChartData } from '@/api/admin';

const overview = ref<DashboardOverview>();
const chartData = ref<ChartDataPoint[]>([]);
const days = ref<'7' | '30'>('7');

onMounted(async () => {
  // 获取核心指标
  const { data } = await getOverview();
  overview.value = data.data;

  // 获取趋势图数据
  const chartRes = await getChartData(days.value);
  chartData.value = chartRes.data.data;
});
</script>
```

## 注意事项

1. **权限控制**: 所有接口都需要管理员权限
2. **错误处理**: 统一返回格式 `{code, message, data}`
3. **参数验证**: API层进行参数校验，服务层可信任参数
4. **事务管理**: 涉及多表操作时使用数据库事务
5. **日志记录**: 重要操作需记录操作日志（待实现）
