## 四、密钥池管理 (Key Pool Management)

> **架构说明**：密钥池采用 MySQL + Redis 双层架构
> - **MySQL**：存储密钥配置（model, key_secret, max_concurrency, weight, status）
> - **Redis**：维护实时状态（并发计数、熔断标记、统计缓冲）

> **⚠️ 重要变更**：模型配置已改为动态管理，不再硬编码
> - 新增 `GET /api/admin/models` 接口获取可用模型列表
> - 支持动态添加新的 AI 模型，无需修改前端代码
> - Model 字段类型从 `enum` 改为 `string`

### 4.1 获取模型列表

**接口路径**：`GET /api/admin/models`

**说明**：获取系统支持的所有模型配置，前端通过此接口动态渲染模型选择器。

**响应示例**：

```json
{
  "code": 0,
  "message": "success",
  "data": [
    {
      "key": "gpt-4",
      "name": "GPT-4",
      "enabled": true,
      "description": "OpenAI GPT-4 模型",
      "color": "bg-green-500",
      "max_concurrency_limit": 20
    },
    {
      "key": "claude-3-opus",
      "name": "Claude 3 Opus",
      "enabled": true,
      "description": "Anthropic Claude 3 Opus 模型",
      "color": "bg-orange-500",
      "max_concurrency_limit": 10
    },
    {
      "key": "midjourney",
      "name": "Midjourney",
      "enabled": true,
      "description": "Midjourney 图像生成",
      "color": "bg-purple-500",
      "max_concurrency_limit": 15
    }
  ]
}
```

**字段说明**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| key | string | ✅ | 模型标识符（用于数据库存储） |
| name | string | ✅ | 模型显示名称 |
| enabled | boolean | ✅ | 是否启用（false 表示禁用，不在前端显示） |
| description | string | ❌ | 模型描述信息 |
| color | string | ❌ | Tailwind CSS 颜色类（用于 UI 展示） |
| max_concurrency_limit | number | ❌ | 该模型建议的最大并发限制 |

### 4.2 创建模型

**接口路径**：`POST /api/admin/models`

**说明**：创建新的AI模型配置。

**请求体**：

```json
{
  "key": "claude-3-sonnet",             // 模型唯一标识
  "name": "Claude 3 Sonnet",            // 显示名称
  "enabled": true,                      // 是否启用
  "description": "Anthropic Claude 3 Sonnet 模型",  // 描述（可选）
  "color": "bg-orange-400",             // Tailwind颜色类（可选）
  "icon_url": "https://example.com/icon.png",  // 图标URL（可选）
  "max_concurrency_limit": 20           // 建议最大并发（可选）
}
```

**字段说明**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| key | string | ✅ | 模型唯一标识（仅支持小写字母、数字、下划线、中划线）|
| name | string | ✅ | 模型显示名称 |
| enabled | boolean | ✅ | 是否启用 |
| description | string | ❌ | 模型描述信息 |
| color | string | ❌ | Tailwind CSS 颜色类 |
| icon_url | string | ❌ | 模型图标URL |
| max_concurrency_limit | number | ❌ | 建议的最大并发限制 |

**响应示例**：

```json
{
  "code": 0,
  "message": "Model created successfully",
  "data": {
    "key": "claude-3-sonnet",
    "name": "Claude 3 Sonnet",
    "enabled": true,
    "description": "Anthropic Claude 3 Sonnet 模型",
    "color": "bg-orange-400",
    "icon_url": "https://example.com/icon.png",
    "max_concurrency_limit": 20,
    "created_at": "2024-01-15T10:30:00Z",
    "updated_at": "2024-01-15T10:30:00Z"
  }
}
```

**错误响应**：

```json
{
  "code": 400,
  "message": "Model key already exists",
  "data": null
}
```

### 4.4 删除模型

**接口路径**：`DELETE /api/admin/models/:key`

**说明**：删除模型配置。

**注意事项**：
- 只有当该模型没有关联的密钥和任务时才能删除
- 如果有关联数据，应先禁用模型（enabled: false）而非删除

**响应示例**：

```json
{
  "code": 0,
  "message": "Model deleted successfully",
  "data": null
}
```

**错误响应（有关联数据）**：

```json
{
  "code": 400,
  "message": "Cannot delete model with existing keys or tasks",
  "data": {
    "key_count": 5,
    "task_count": 120
  }
}
```

### 4.5 获取密钥列表

**接口路径**：`GET /api/admin/keys`

**请求参数**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| model | string | 否 | - | 模型筛选（gpt-4、claude-3-opus 等） |

**响应示例**：

```json
{
  "code": 0,
  "message": "Success",
  "data": [
    {
      "id": 1,
      "model": "gpt-4",                     // 模型标识
      "api_base": "https://api.openai.com/v1", // API 基础地址
      "key_secret": "sk-proj-abc****xyz",   // 密钥（脱敏：前8位 + **** + 后4位）
      "max_concurrency": 3,                 // 最大并发限制
      "weight": 10,                         // 权重（用于负载均衡，1-100）
      "status": 1,                          // 状态：1=启用，0=手动停用

      // 统计字段（MySQL 存储，定时从 Redis 同步）
      "total_calls": 15420,                 // 总调用次数
      "total_errors": 23,                   // 总失败次数

      // 实时状态（从 Redis 读取）
      "current_usage": 2,                   // 当前并发数（0-max_concurrency）
      "is_cooling": false,                  // 是否在冷却期（熔断中）
      "cooling_until": null,                // 冷却结束时间（ISO 8601，冷却中才有值）

      "last_used_at": "2024-03-20T15:30:00Z",  // 最后使用时间
      "created_at": "2024-03-01T10:00:00Z"
    },
    {
      "id": 2,
      "model": "gpt-4",
      "api_base": "https://api.openai.com/v1", // API 基础地址
      "key_secret": "sk-proj-def****uvw",
      "max_concurrency": 5,
      "weight": 20,
      "status": 1,
      "total_calls": 8930,
      "total_errors": 156,
      "current_usage": 5,                   // 并发已满
      "is_cooling": false,
      "cooling_until": null,
      "last_used_at": "2024-03-20T16:00:00Z",
      "created_at": "2024-03-05T14:00:00Z"
    },
    {
      "id": 3,
      "model": "claude-3-opus",
      "api_base": "https://api.anthropic.com", // API 基础地址
      "key_secret": "sk-ant-xyz****abc",
      "max_concurrency": 2,
      "weight": 5,
      "status": 1,
      "total_calls": 234,
      "total_errors": 45,
      "current_usage": 0,
      "is_cooling": true,                   // 正在冷却（触发了熔断）
      "cooling_until": "2024-03-20T16:10:00Z",  // 预计恢复时间
      "last_used_at": "2024-03-20T16:05:00Z",
      "created_at": "2024-03-15T09:00:00Z"
    }
  ]
}
```

**字段说明**：
- `max_concurrency`：核心配置，控制该 Key 同时运行的任务数上限
- `weight`：权重越高，被选中的概率越大（用于"大号优先"策略）
- `current_usage`：从 Redis `pool:usage:{key_id}` 实时读取
- `is_cooling` / `cooling_until`：从 Redis `pool:cooldown:{key_id}` 读取（TTL 300s）

### 4.6 添加密钥

**接口路径**：`POST /api/admin/keys`

**请求 Body**：

```json
{
  "model": "gpt-4",                  // 模型标识（必填）
  "api_base": "https://api.openai.com/v1", // API 基础地址（可选）
  "key_secret": "sk-proj-abc123...", // API 密钥完整串（必填）
  "max_concurrency": 3,              // 最大并发数（可选，默认 3）
  "weight": 10                       // 权重（可选，默认 10）
}
```

**响应示例**：

```json
{
  "code": 0,
  "message": "Key added successfully",
  "data": {
    "id": 4,
    "model": "gpt-4",
    "api_base": "https://api.openai.com/v1",
    "key_secret": "sk-proj-ab****",    // 返回时已脱敏
    "max_concurrency": 3,
    "weight": 10,
    "status": 1,
    "created_at": "2024-03-20T17:00:00Z"
  }
}
```

### 4.7 批量添加密钥

**接口路径**：`POST /api/admin/keys/batch`

**请求 Body**：

```json
{
  "model": "gpt-4",                  // 模型（必填）
  "api_base": "https://api.openai.com/v1", // API 基础地址（可选，统一设置）
  "keys": [                          // 密钥数组（必填，最多 100 个）
    "sk-proj-abc123...",
    "sk-proj-def456...",
    "sk-proj-ghi789..."
  ],
  "max_concurrency": 3,              // 统一的最大并发（可选，默认 3）
  "weight": 10                       // 统一的权重（可选，默认 10）
}
```

**响应示例**：

```json
{
  "code": 0,
  "message": "Batch import completed",
  "data": {
    "success_count": 3,              // 成功导入数量
    "failed_count": 0,               // 失败数量
    "failed_keys": []                // 失败的密钥列表（脱敏）
  }
}
```

### 4.10 手动触发熔断/解除熔断

**接口路径**：`POST /api/admin/keys/{id}/cooldown`

**路径参数**：

| 参数 | 类型 | 说明 |
|------|------|------|
| id | integer | 密钥 ID |

**请求 Body**：

```json
{
  "action": "trigger",   // 操作：trigger（触发熔断）、release（解除熔断）
  "duration": 300        // 冷却时长（秒，仅 trigger 时需要，默认 300）
}
```

**响应示例**：

```json
{
  "code": 0,
  "message": "Cooldown triggered successfully",
  "data": {
    "cooling_until": "2024-03-20T16:15:00Z"
  }
}
```

### 4.11 触发健康检测

**接口路径**：`POST /api/admin/keys/health-check`

**请求参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| model | string | 否 | 指定模型检测（不填则检测所有） |

**说明**：
- 后端调用各模型 API 验证密钥有效性
- 检测结果会更新密钥状态和错误计数
- 建议异步执行，返回任务 ID 供前端轮询

**响应示例**（同步方式）：

```json
{
  "code": 0,
  "message": "Health check completed",
  "data": {
    "total": 10,           // 总密钥数
    "active": 7,           // 正常可用
    "cooling": 2,          // 冷却中
    "disabled": 1,         // 手动停用
    "details": [           // 详细结果
      {
        "id": 1,
        "model": "gpt-4",
        "status": 1,
        "is_cooling": false,
        "check_result": "ok"
      },
      {
        "id": 3,
        "model": "claude-3-opus",
        "status": 1,
        "is_cooling": true,
        "check_result": "rate_limit"
      }
    ]
  }
}
```

**响应示例**（异步方式）：

```json
{
  "code": 0,
  "message": "Health check started",
  "data": {
    "task_id": "health_check_12345",   // 任务 ID
    "estimated_time": 30                // 预计耗时（秒）
  }
}
```
