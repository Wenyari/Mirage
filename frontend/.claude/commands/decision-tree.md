# 决策树文档生成

快速启动决策树文档生成任务，帮助你创建结构化的配置手册、QA清单或故障排查指南。

## 使用方式

输入 `/decision-tree` 启动此命令，系统将引导你完成以下流程：

1. **选择文档类型**：配置手册、QA清单、故障排查指南
2. **确认目标用户**：开发者、QA、运维、最终用户
3. **明确覆盖范围**：核心功能、完整功能、特定模块
4. **生成决策树文档**：自动调用 decision-tree-writer Agent

## 支持的文档类型

### 1. 配置手册 (Configuration Manual)
- **用途**：引导用户完成产品配置、环境设置
- **特点**：决策树形式，按场景分流
- **示例场景**：
  - 组件配置向导
  - 环境部署指南
  - 主题定制手册

### 2. QA清单 (QA Checklist)
- **用途**：系统化QA测试流程、发布前验证
- **特点**：检查项清单，决策树测试流程
- **示例场景**：
  - 功能测试清单
  - 回归测试流程
  - 发布验证检查

### 3. 故障排查指南 (Troubleshooting Guide)
- **用途**：Bug诊断、性能问题、错误排查
- **特点**：症状驱动，诊断决策树
- **示例场景**：
  - 常见问题诊断
  - 性能问题排查
  - 错误代码解析

## 工作流程

此命令将执行以下步骤：

1. **收集需求**
   - 使用交互式问题确认文档类型
   - 了解目标用户和使用场景
   - 确定详细程度和覆盖范围

2. **启动 Agent**
   - 自动调用 `decision-tree-writer` Agent
   - 传递收集的需求信息
   - 开始生成决策树文档

3. **生成文档**
   - 创建主决策树（Mermaid + 文本）
   - 展开各分支详细内容
   - 添加辅助材料（参考表、检查清单）

4. **质量验证**
   - 检查决策树逻辑完整性
   - 验证 Mermaid 图表语法
   - 确保解决方案具体可执行

## 注意事项

- **明确需求**：尽量提供详细的背景信息，帮助生成更精准的文档
- **选择模板**：不同文档类型使用不同的模板结构
- **迭代优化**：初稿生成后可根据反馈进行调整
- **保持更新**：决策树文档应随产品版本更新
