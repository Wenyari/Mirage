# 项目元信息配置

这个目录包含用于文档生成的项目元信息配置文件。

## 文件说明

### project.yaml

包含项目的准确元信息，用于 `write_doc` skill 生成技术文档时引用，避免模型臆造内容。

**包含的信息：**
- 项目基本信息（名称、版本、仓库等）
- 开发环境要求（Node.js、IDE 等）
- 核心依赖及版本
- 开发、测试、构建命令
- 部署信息（NPM、CDN）
- 团队约定（代码规范、Git 流程）
- 架构设计信息
- 常见问题解决方案

## 使用方式

当使用 `write_doc` skill 生成文档时，该 skill 会自动读取此配置文件获取准确信息。

**禁止臆造的内容：**
- 版本号和环境要求
- 命令和脚本
- 路径和文件名
- 部署地址

**如果信息缺失：**
- 使用占位符（如 `[待补充：具体信息]`）而非猜测
- 在配置文件中补充缺失信息

## 更新频率

信息更新频率较低，建议在以下情况更新：
- 项目版本发布时
- 核心依赖升级时
- 开发流程变更时
- 新增重要命令或工具时

## 维护建议

1. 保持信息准确性，定期检查与实际情况是否一致
2. 版本号应与 package.json 同步
3. 命令应与 package.json scripts 一致
4. 添加注释说明特殊配置的原因
