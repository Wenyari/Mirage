# Decision Tree Writer 使用指南

## 概述

这是一个专门用于生成决策树形式文档的 Claude Code 扩展，包括配置手册、QA清单和故障排查指南。

## 文件结构

```
.claude/
├── skills/
│   └── decision-tree-writer/          # Skill 定义
│       ├── SKILL.md                   # Skill 配置和规范
│       └── templates/                 # 文档模板
│           ├── configuration-manual.md
│           ├── qa-checklist.md
│           └── troubleshooting-guide.md
│
├── agents/
│   └── decision-tree-writer.md        # Agent 配置
│
├── commands/
│   └── decision-tree.md               # Slash Command
│
└── config.mts                         # 配置注册文件
```

## 使用方式

### 方式 1: 使用 Slash Command（推荐）

最简单的方式是使用 `/decision-tree` 命令：

```
/decision-tree
```

系统会引导你选择：
- 文档类型（配置手册/QA清单/故障排查指南）
- 目标用户
- 覆盖范围

### 方式 2: 直接调用 Agent

如果你已经明确需求，可以直接请求：

```
请使用 decision-tree-writer agent 创建一个paradigm-chart图表渲染问题的故障排查指南
```

### 方式 3: 使用 Skill

在其他任务中引用这个 Skill：

```
我需要在文档中加入一个决策树形式的配置指南，请使用 decision-tree-writer skill
```

## 功能特性

### ✅ 支持的文档类型

1. **配置手册 (Configuration Manual)**
   - 引导用户完成复杂配置
   - 按使用场景分流
   - 包含代码示例和验证方法

2. **QA清单 (QA Checklist)**
   - 系统化测试流程
   - 决策树式测试导航
   - Bug记录和分类

3. **故障排查指南 (Troubleshooting Guide)**
   - 症状驱动的诊断流程
   - 详细的解决方案
   - 常见问题快速索引

### ✅ 输出格式

每份文档都包含：
- **Mermaid 可视化决策树**：直观的流程图
- **文本形式决策树**：便于复制和无渲染环境使用
- **详细解决方案**：包含代码示例、验证步骤
- **快速参考表**：问题→解决方案映射
- **检查清单**：验证完成度

## 示例场景

### 场景 1: 创建雷达图配置手册

```
用户: 帮我创建一个雷达图配置手册，包含不同使用场景的配置指导

Agent 会生成:
- 主决策树（按数据量、场景类型分流）
- 每个场景的详细配置步骤
- 配置参数对照表
- 验证方法
```

### 场景 2: 创建发布前 QA 清单

```
用户: 我需要一个 v1.12.0 发布前的 QA 测试清单

Agent 会生成:
- 测试流程决策树
- 功能测试检查项
- 性能测试标准
- Bug 分类和记录模板
- 发布通过标准
```

### 场景 3: 创建故障排查指南

```
用户: 创建一个图表不显示问题的故障排查指南

Agent 会生成:
- 症状诊断决策树
- 各种原因的详细诊断流程
- 具体解决方案和代码示例
- 快速参考映射表
```

## 质量标准

生成的文档自动满足以下标准：

- ✅ 决策树深度不超过 4 层
- ✅ 每个决策点 2-4 个分支
- ✅ 所有分支有明确的终止状态
- ✅ 包含 Mermaid 和文本两种形式
- ✅ 提供具体的代码示例
- ✅ 包含验证方法
- ✅ 无逻辑死循环

## 最佳实践

### 1. 提供清晰的需求
❌ 差: "帮我写个文档"
✅ 好: "帮我创建一个雷达图配置手册，覆盖小数据量和大数据量两种场景"

### 2. 明确目标用户
- 开发者：需要技术细节和代码示例
- QA：需要测试流程和验证标准
- 最终用户：需要简化的步骤指导

### 3. 确定覆盖范围
- 核心功能：只包含最常用的场景
- 完整功能：包含所有场景和边界情况
- 特定模块：只针对某个组件或功能

### 4. 迭代优化
- 先生成骨架结构确认方向
- 再逐步展开详细内容
- 根据反馈调整和补充

## 常见问题

### Q: 决策树太深怎么办？
A: Agent 会自动控制深度不超过 4 层。如果内容复杂，会拆分成多个子决策树。

### Q: 可以同时生成多种文档类型吗？
A: 可以。一次性指定多个需求，Agent 会分别生成。

### Q: Mermaid 图表不显示怎么办？
A: 所有决策树都提供文本版本作为备份，可以正常使用。

### Q: 如何更新已生成的文档？
A: 直接说明需要修改的部分，Agent 会基于现有内容进行更新。

## 技术细节

### Skill 架构
- **SKILL.md**: 定义工作流程和规范
- **templates/**: 提供三种文档类型的模板

### Agent 能力
- 需求分析和澄清
- 决策树结构设计
- Mermaid 图表生成
- 内容质量验证
- 多轮迭代优化

### 集成方式
- 可以在其他 workflow 中调用
- 支持 Task tool 集成
- 可以与其他 skills 组合使用
