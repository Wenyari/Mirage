## 核心功能

本 Skill 用于快速定位代码实现、分析调用关系，类似 VSCode 全局搜索的增强版。

**使用场景**：
- 用户通过命令主动触发代码查找
- 需要快速了解某个函数/类的定义位置和调用关系
- 通过功能描述反向查找相关代码实现

## 工作流程

### 场景判断

**场景 1：已知代码片段**（如 `functionName`、`ClassName`、`variable_name`）
- 用户输入包含明确的代码语法标识符

**场景 2：功能描述**（如 "雷达图配置"、"主题系统"）
- 用户输入是自然语言描述

### 场景 1：已知代码片段查找

**步骤**：
1. 使用 Grep 搜索代码片段在所有文件中的出现（`output_mode: "files_with_matches"`）
2. 使用 Grep 获取上下文（`output_mode: "content"`, `-C: 3`）
3. 基于文本模式识别定义位置和引用位置
4. 分析调用关系（import 语句、函数调用等）

**定义位置识别模式**（JavaScript/TypeScript）：
- `function <name>`
- `class <name>`
- `const <name> =`
- `let <name> =`
- `export { <name> }`
- `export function <name>`
- `export class <name>`
- `export const <name>`

### 场景 2：功能描述查找

**步骤**：
1. 搜索 README.md 和 docs/ 目录下的文档，找相似功能描述
2. 从文档中提取可能的代码片段（模块名、类名、关键术语）
3. 使用 Glob 浏览代码仓库目录结构（src/、packages/ 等）
4. 综合判断最可能的代码片段
5. 转入场景 1 的流程进行详细分析

**文档搜索优先级**：
- README.md
- docs/**/*.md
- CHANGELOG.md
- 代码注释中的文档块

## 工具调用策略

### 必须使用的工具

1. **Grep** - 搜索代码片段
   - 第一阶段：`output_mode: "files_with_matches"` - 快速定位文件
   - 第二阶段：`output_mode: "content"`, `-C: 3` - 获取上下文

2. **Read** - 读取文档文件（场景 2）

3. **Glob** - 查找文档和匹配目录结构（场景 2）

### 禁止使用的工具

- ❌ Task 代理（会增加延迟，违反快速查找原则）
- ❌ Bash 执行复杂分析（保持简单）

### 性能优化策略

1. **限制搜索范围**：
   - 使用 Grep 的 `glob` 参数（如 `"*.ts"`, `"*.js"`, `"src/**/*.tsx"`）
   - 优先搜索源码目录（src/、packages/、lib/）

2. **跳过无关目录**：
   - 自动跳过 node_modules/、dist/、build/、.git/、coverage/
   - Grep 默认已过滤这些目录

3. **结果限制**：
   - 使用 `head_limit` 参数限制初始结果数量
   - 如果匹配超过 50 个文件，发出警告

## 边界情况处理

### 空结果
```markdown
未找到匹配结果。建议：
- 检查拼写是否正确
- 尝试更宽泛的搜索词（如只搜索部分名称）
- 使用正则表达式模式（如 `radar.*config`）
```

### 大量结果（>50 个文件）
```markdown
⚠️ 警告：找到 X 个匹配文件，搜索词可能过于通用。

建议细化搜索：
- 添加更多上下文（如 `RadarChart` 而不是 `radar`）
- 限制文件类型（如只搜索 .ts 文件）
- 使用更精确的模式
```

### 场景 2 无文档匹配
```markdown
在文档中未找到相关描述。建议：
- 提供更多上下文或关键词
- 直接使用可能的代码片段名称进行搜索
- 浏览项目目录结构寻找线索
```

## 准确性限制与说明

### 必须在报告末尾添加的注意事项

```markdown
## ⚠️ 注意事项
- **分析方法**：本报告基于文本匹配，不是语义级别的精确分析
- **可能误报**：结果可能包含注释、字符串字面量、测试用例中的引用
- **调用关系**：调用关系分析基于简单模式匹配，可能遗漏动态调用
- **建议**：对于关键代码，建议使用 IDE 的 "Find All References" 功能进行二次验证
- **局限性**：无法识别通过 eval、动态 import 等方式的引用
```
