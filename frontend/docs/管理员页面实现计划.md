# AIGC 平台管理员后台实现计划

## 项目概述

实现一个完整的管理员后台系统，包含 6 个主要页面和配套基础设施。

**技术栈**：
- React 19 + TypeScript + Vite 7
- shadcn/ui (Radix UI + Tailwind CSS)
- TanStack Query v5 (数据管理)
- React Hook Form + Zod (表单)
- React Router v6 (路由)
- MSW (Mock 数据)
- Recharts (图表)
- TanStack Table (表格)
- axios (HTTP 客户端)
- Zustand (状态管理)

**后端状态**：使用 MSW 提供 Mock 数据，所有接口前缀 `/api/admin`

**路由前缀**：`/wadminw`

**认证策略**：实现完整登录页面和 Token 管理，但暂时不启用，直接进入管理主页

## 技术要点

### 1. Axios 配置
```typescript
// src/lib/api.ts
import axios from 'axios';

const api = axios.create({
  baseURL: '/api',
  timeout: 10000,
});

// 请求拦截器：添加 JWT Token
api.interceptors.request.use(config => {
  const token = localStorage.getItem('token');
  if (token) config.headers.Authorization = `Bearer ${token}`;
  return config;
});

// 响应拦截器：处理 401
api.interceptors.response.use(
  response => response.data,
  error => {
    if (error.response?.status === 401) {
      // 跳转登录
    }
    return Promise.reject(error);
  }
);
```

export function useUpdateBalance() {
  const queryClient = useQueryClient();
  return useMutation({
    mutationFn: ({ userId, amount, reason }) => updateUserBalance(userId, amount, reason),
    onSuccess: () => {
      queryClient.invalidateQueries({ queryKey: ['admin', 'users'] });
    },
  });
}
