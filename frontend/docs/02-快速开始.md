# 快速开始

## 简要说明

本文档将帮助您在 **5 分钟内**完成 Mirage 项目的环境搭建和运行，适合首次接触本项目的开发者快速上手。

## 前置要求

### 必需环境

| 工具 | 版本要求 | 说明 |
|------|---------|------|
| **Node.js** | 16.x 或 18.x LTS | 推荐使用 LTS 长期支持版本 |
| **包管理器** | npm / pnpm / yarn | 项目使用 npm，也兼容 pnpm 和 yarn |

### 推荐工具

- **IDE**：Visual Studio Code
  - 推荐插件：ESLint、Prettier、TypeScript
- **浏览器**：Chrome、Firefox、Safari 或 Edge 的最新版本

### 检查环境

```bash
# 检查 Node.js 版本
node --version
# 应输出 v16.x.x 或 v18.x.x

# 检查 npm 版本
npm --version
```

## 安装步骤

### 1. 克隆仓库

```bash
# 使用 Git 克隆项目（替换为实际仓库地址）
git clone <仓库地址>

# 进入项目目录
cd frontend
```

### 2. 安装依赖

```bash
# 使用 npm
npm install

# 或使用 pnpm（更快）
pnpm install

# 或使用 yarn
yarn install
```

**预计安装时间**：首次安装约需 2-5 分钟，取决于网络速度。

### 3. 环境配置（可选）

如果需要连接真实后端 API，请确认 `vite.config.ts` 中的代理配置：

```typescript
// vite.config.ts
server: {
  proxy: {
    '/api': {
      target: 'http://localhost:5000',  // 修改为实际后端地址
      changeOrigin: true,
    },
  },
}
```

**说明**：
- 默认代理地址为 `http://localhost:5000`
- 如果后端服务运行在其他地址，需修改 `target` 字段

## 运行开发环境

### 启动开发服务器

```bash
npm run dev
```

**启动成功标志**：

```
  VITE v7.2.4  ready in XXX ms

  ➜  Local:   http://localhost:5173/
  ➜  Network: use --host to expose
  ➜  press h + enter to show help
```

### 访问应用

在浏览器中打开以下地址：

| 入口 | 地址 | 说明 |
|------|------|------|
| **用户前台** | http://localhost:5173/ | 用户端应用首页 |
| **管理后台** | http://localhost:5173/wadminw | 管理员后台（需要登录） |
| **用户登录** | http://localhost:5173/login | 用户登录页面 |
| **管理员登录** | http://localhost:5173/wadminw/login | 管理员登录页面 |

### 开发模式特性

- **热更新（HMR）**：修改代码后自动刷新页面
- **React Query DevTools**：右下角会显示查询状态调试工具
- **MSW Mock**：开发环境下自动启用 Mock 数据（如果配置）

## 构建产物

### 构建生产版本

```bash
# 执行构建
npm run build
```

**构建流程**：

1. **TypeScript 类型检查**：`tsc -b`
2. **Vite 打包**：生成优化后的静态文件

**输出目录**：`dist/`

```
dist/
├── assets/
│   ├── index-[hash].js    # 打包后的 JavaScript
│   └── index-[hash].css   # 打包后的 CSS
└── index.html             # 入口 HTML 文件
```

### 预览构建产物

```bash
npm run preview
```

**访问地址**：http://localhost:4173/

**说明**：此命令会启动一个静态文件服务器，用于预览生产构建的结果。

## 最小使用示例

### 1. 启动项目并访问首页

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

访问 http://localhost:5173/ 即可看到用户前台首页。

### 2. 测试管理后台

访问 http://localhost:5173/wadminw/login 进入管理员登录页面：

- **使用 Mock 数据**：如果配置了 MSW，可以直接使用 Mock 账号登录
- **连接后端 API**：需要确保后端服务已启动并配置正确的代理地址

### 3. 验证 API 请求

打开浏览器开发者工具（F12）的 Network 标签，查看是否正确发送了 API 请求。

**成功标志**：
- 请求路径以 `/api` 开头
- 请求被正确代理到后端服务
- 或被 MSW 拦截并返回 Mock 数据

## 快速排查问题

### 依赖安装失败

**可能原因**：
- 网络问题
- Node.js 版本过低

**解决方案**：

```bash
# 清除 npm 缓存
npm cache clean --force

# 删除 node_modules 和 lock 文件
rm -rf node_modules package-lock.json

# 重新安装
npm install
```

### 开发服务器无法启动

**可能原因**：
- 端口 5173 被占用
- 依赖未正确安装

**解决方案**：

```bash
# 检查端口占用（Windows）
netstat -ano | findstr :5173

# 检查端口占用（Linux/Mac）
lsof -i :5173

# 或指定其他端口启动
npm run dev -- --port 3000
```

### TypeScript 类型错误

**可能原因**：
- TypeScript 版本不匹配
- 类型定义文件缺失

**解决方案**：

```bash
# 重新安装依赖
npm install

# 手动检查类型错误
npx tsc --noEmit
```

### API 请求 404 或 CORS 错误

**可能原因**：
- 后端服务未启动
- Vite 代理配置错误

**解决方案**：

1. 确认后端服务已启动并监听正确端口
2. 检查 `vite.config.ts` 中的 `proxy` 配置
3. 查看浏览器控制台和终端的错误日志
