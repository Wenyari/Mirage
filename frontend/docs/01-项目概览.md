# 项目概览

## 简要说明

**Mirage** 是一个基于 React + TypeScript 构建的 AI 模型管理平台，提供完整的模型服务管理、用户权限控制、CDK 兑换系统和 AI 对话/视频生成等功能。

## 项目定位

Mirage 平台分为两大核心模块：

- **管理后台**：面向管理员的系统管理平台，提供用户管理、模型配置、密钥池管理、数据统计等功能
- **用户前台**：面向终端用户的 AI 服务平台，提供模型广场、对话聊天、视频生成、积分管理等功能

## 核心功能

### 管理后台功能

| 功能模块 | 路由路径 | 说明 |
|---------|----------|------|
| **数据概览** | `/wadminw/dashboard` | 展示平台用户增长、Token 使用量等关键指标 |
| **用户管理** | `/wadminw/users` | 管理用户信息、余额、等级、状态等 |
| **CDK 管理** | `/wadminw/cdk` | 生成和管理兑换码，支持批量生成和导出 |
| **密钥池管理** | `/wadminw/keys` | 管理 API 密钥池，监控密钥使用状态 |
| **模型配置** | `/wadminw/model-configs` | 配置模型参数、定价策略等 |
| **模型管理** | `/wadminw/models` | 管理可用的 AI 模型列表 |
| **测试平台** | `/wadminw/playground` | 管理员测试 AI 模型功能 |

### 用户前台功能

| 功能模块 | 路由路径 | 说明 |
|---------|----------|------|
| **首页** | `/` | 平台首页和导航入口 |
| **模型广场** | `/models` | 展示可用的 AI 模型列表 |
| **探索功能** | `/explore/*` | 包含 Prompts、Agents、Workflows 等资源 |
| **对话平台** | `/playground/chat` | AI 对话聊天功能 |
| **视频生成** | `/playground/video` | AI 视频生成功能 |
| **设置中心** | `/setting/*` | 用户设置、积分管理、API 密钥、使用记录等 |
| **更多** | `/more/*` | 平台更新、活动、社区等内容 |

## 技术栈

### 核心技术

- **框架**：React 19.2.0 + TypeScript 5.9.3
- **构建工具**：Vite 7.2.4
- **路由**：React Router v6.30.2
- **状态管理**：Zustand 5.0.9
- **数据请求**：TanStack Query 5.90.15 + Axios 1.13.2

### UI 与样式

- **UI 组件库**：Radix UI（20+ 组件）
- **样式方案**：Tailwind CSS 3.4.17
- **图标库**：Lucide React 0.562.0
- **图表库**：Recharts 2.15.4
- **工具类**：class-variance-authority、clsx、tailwind-merge

### 开发工具

- **表单管理**：React Hook Form 7.69.0 + Zod 3.25.76
- **表格组件**：TanStack Table 8.21.3
- **Mock 数据**：MSW 2.12.7
- **日期处理**：date-fns 4.1.0
- **Excel 导出**：xlsx 0.18.5
- **Toast 通知**：sonner 1.7.4

### 代码质量

- **Linter**：ESLint 9.39.1 + TypeScript ESLint 8.46.4
- **格式化**：Prettier（通过 eslint-config-prettier）
- **其他插件**：
  - eslint-plugin-react-hooks - React Hooks 规则检查
  - eslint-plugin-jsx-a11y - 无障碍访问检查
  - eslint-plugin-tailwindcss - Tailwind CSS 类名规范
  - eslint-plugin-simple-import-sort - 导入语句自动排序

## 开发环境要求

- **Node.js**：建议使用 16.x 或 18.x LTS 版本
- **包管理器**：npm、pnpm 或 yarn
- **浏览器**：支持现代浏览器（Chrome、Firefox、Safari、Edge）

## 后端 API 配置

项目通过 Vite 代理转发 API 请求到后端服务：

```typescript
// vite.config.ts
server: {
  proxy: {
    '/api': {
      target: 'http://localhost:5000',
      changeOrigin: true,
    },
  },
}
```

**说明**：所有以 `/api` 开头的请求会被代理到 `http://localhost:5000`。

## 认证机制

### JWT Token 管理

- **存储位置**：`localStorage.getItem('auth_token')`
- **请求拦截**：自动在请求头添加 `Authorization: Bearer <token>`
- **响应拦截**：
  - 401 未授权时自动清除 Token 并跳转登录页
  - 根据路径判断跳转到管理后台或用户前台登录页

### 权限控制

- **管理后台**：通过 `AdminGuard` 组件保护 `/wadminw` 路由
- **用户前台**：部分功能需要登录后访问

## Mock 数据开发

项目使用 **MSW (Mock Service Worker)** 进行接口 Mock，支持在开发环境无需后端即可运行：

```typescript
// src/mocks/browser.ts
import { setupWorker } from 'msw/browser';
import { handlers } from './handlers';

export const worker = setupWorker(...handlers);
```
