
# AIGC 平台管理员后台 - AI Coding 开发指南

## 第一部分：后端 Admin API 接口清单 (Backend Contract)

**约定**：

1. 所有接口路径前缀：`/api/admin`。
2. 鉴权方式：Header 携带 `Authorization: Bearer <token>`。
3. 权限校验：后端必须校验 `current_user.role == 'admin'`，否则返回 403。

### 1. 仪表盘 (Dashboard)

* `GET /api/admin/stats/overview`: 获取核心指标（今日新增用户、今日消耗 Token、估算收入、活跃任务数）。
* `GET /api/admin/stats/chart`: 获取近 7 天/30 天的趋势数据（用户增长、Token 消耗）。

### 2. 用户管理 (User Management)

* `GET /api/admin/users`: 获取用户列表（分页、支持按邮箱搜索、按等级筛选）。
* `GET /api/admin/users/{user_id}/details`: 获取特定用户的详细信息（含近期流水、任务记录）。
* `PATCH /api/admin/users/{user_id}/balance`: **人工充值/扣费**（Body: `{"amount": 100, "reason": "补偿"}`，正数加，负数减）。
* `PATCH /api/admin/users/{user_id}/profile`: **修改资料**（Body: `{"level": 3, "status": 0}`，修改等级 T1-T5 或封禁）。

### 3. CDK 兑换码 (CDK Management)

* `POST /api/admin/cdk/generate`: **批量生成**（Body: `{"amount": 500, "count": 20, "type": "once", "batch_name": "内测"}`）。
* `GET /api/admin/cdk`: 获取 CDK 列表（分页、按批次筛选、按状态筛选）。
* `POST /api/admin/cdk/void`: **批量作废**（Body: `{"batch_no": "..."}` 或 `{"ids": [...]}`）。

### 4. 密钥池管理 (Key Pool)

* `GET /api/admin/keys`: 获取所有 Key 列表及状态。
* `POST /api/admin/keys`: **添加 Key**（Body: `{"platform": "openai", "key": "sk-...", "weight": 10}`）。
* `DELETE /api/admin/keys/{id}`: 删除 Key。
* `POST /api/admin/keys/check`: **触发连通性检测**（后端异步检测所有 Key，前端轮询或等待返回）。

### 5. 模型与配置 (Models & Config)

* `GET /api/admin/models`: 获取模型配置列表（包含价格倍率、T1-T5 限制）。
* `PATCH /api/admin/models/{model_id}`: 修改模型配置（Body: `{"base_cost": 50, "is_active": true, "vip_limit": 2}`）。
* `GET /api/admin/config/membership`: 获取 T1-T5 等级的具体权益配置。
* `PUT /api/admin/config/membership`: 更新 T1-T5 的权益参数。

### 6. 测试沙箱 (Playground)

* `POST /api/admin/test/generate`: **管理员专用生成接口**（不扣费，返回详细 Debug 信息，如使用的 Key、耗时、上游原始响应）。

## 第二部分：前端技术方案 (Frontend Spec)

**技术栈**:

* **Framework**: React 18 + TypeScript + Vite
* **UI Library**: shadcn/ui (Radix UI + Tailwind CSS)
* **State/Data Fetching**: TanStack Query (React Query) v5
* **Form**: React Hook Form + Zod
* **Routing**: React Router v6
* **Icons**: Lucide React

**目录结构建议**
建议将 Admin 代码与前台 User 代码在 pages 目录下物理隔离，保持整洁。

### 1. 全局架构与路由

* **Layout**: `layouts/AdminLayout.tsx`
* 左侧固定 Sidebar（使用 `shadcn/ui` 的 `NavigationMenu` 或自定义 Sidebar）。
* 顶部 Header（面包屑 Breadcrumb、ThemeToggle、Logout）。
* 内容区 `<Outlet />`。


* **Auth Guard**: `components/auth/AdminGuard.tsx`
* 检查 Store 中的 `user.role`。如果不为 `'admin'`，重定向至 `/login` 或 `/404`。


* **路由表**:
* `/wadminw/dashboard` (Index)
* `/wadminw/users`
* `/wadminw/cdk`
* `/wadminw/keys`
* `/wadminw/models`
* `/wadminw/playground`



### 2. 详细页面拆解 (AI Coding Prompt 指南)

#### 2.1 仪表盘页面 (`pages/admin/Dashboard.tsx`)

* **UI 构成**:
* 顶部 4 个 `Card` 组件：展示 `overview` 接口的数据（总用户、总收入等）。
* 中部 2 个图表区域：使用 `Recharts` 绘制。
* 左侧：新增用户趋势 (LineChart)。
* 右侧：API 调用量/Token消耗 (BarChart)。




* **数据**: `useQuery(['adminStats'])`。

#### 2.2 用户管理页面 (`pages/admin/UserManager.tsx`)

* **UI 构成**:
* 顶部筛选栏：SearchInput (邮箱), Select (等级), Select (状态)。
* **核心表格**: 使用 `@tanstack/react-table`。
* **Columns**: ID, Avatar+Email, Level (Badge显示T1-T5), Balance, Status (Switch组件), Actions.
* **Pagination**: 底部分页控件。


* **编辑弹窗 (Dialog)**:
* 点击 "Edit" 触发。
* 表单字段：等级 (Select T1-T5), 状态 (Radio), 备注。


* **充值弹窗 (Dialog)**:
* 点击 "Recharge" 触发。
* 表单字段：变动金额 (Input type=number, 允许负数), 原因 (Input)。




* **交互**:
* Switch 切换状态直接调用 `mutation` 封禁/解封。
* 充值成功后 `invalidateQueries(['users'])` 刷新列表。



#### 2.3 CDK 管理页面 (`pages/admin/CDKManager.tsx`)

* **UI 构成**:
* **生成区 (Card)**: 一个内嵌表单。
* Fields: 面额, 数量, 批次名, 类型(单次/通用)。
* Submit Button: "生成并导出"。


* **列表区**: 数据表格。
* **Columns**: Code (前6位明文+****), Value, Batch, Status (Badge: Used/Unused), User (若已用显示邮箱), Time.




* **交互**:
* 生成成功后，前端根据返回的 JSON 数据，使用 `xlsx` 库或 Blob 自动触发 Excel/CSV 下载。



#### 2.4 模型与等级管理页面 (`pages/admin/ModelManager.tsx`)

* **UI 构成 (Tabs)**:
* **Tab 1: 模型列表**:
* 表格展示所有模型。
* 列：ModelID, Name, Cost (Input 实时编辑), Status (Switch), Actions.
* 支持直接在表格行内修改价格倍率并保存。


* **Tab 2: 等级配置 (Membership)**:
* 展示 T1 - T5 的 5 个卡片。
* 每个卡片内包含：并发数限制 (Input), 队列权重 (Slider/Input)。
* 底部保存按钮 "Update Configs"。





#### 2.5 密钥池管理页面 (`pages/admin/KeyPool.tsx`)

* **UI 构成**:
* 顶部：`Add Key` 按钮 (触发 Dialog), `Check Health` 按钮 (触发全量检测)。
* **列表**:
* **Columns**: Platform (Icon), Key (Sk-****), Weight, Status (Badge: Active/Error/RateLimit), LastUsed.


* **添加弹窗**:
* Textarea: 支持批量粘贴，每行一个 `key`。




* **交互**:
* 状态列的 Badge 颜色根据后端返回动态变化（Green/Red/Yellow）。



#### 2.6 测试沙箱页面 (`pages/admin/Playground.tsx`)

* **UI 构成**:
* 类似 Postman 的两栏布局。
* **左侧 (Config)**: Select Model, Textarea Prompt, JSON Input Params.
* **右侧 (Result)**:
* **Tab 1: Preview**: 展示生成的图片/视频（直接渲染 URL）。
* **Tab 2: Debug JSON**: 使用 `<pre>` 标签展示后端返回的完整元数据（排查 Key 问题）。




* **交互**:
* 提交时调用 `/api/admin/test/generate`。
* Loading 状态需明显。

## 第三部分：AI Coding 提示词建议 (Prompt Strategy)

当你使用 AI 生成代码时，建议按以下顺序进行，每次只给一个模块的指令：

**Step 1: 基础组件与 API 封装**

> "我是 React + shadcn/ui 项目。请为我封装 `src/lib/api.ts`，使用 axios，配置拦截器处理 JWT 和 401 跳转。然后创建 `src/services/admin.ts`，按照我提供的后端 API 清单，定义所有 Admin 相关的 API 请求函数。"

**Step 2: 布局与路由**

> "创建 `layouts/AdminLayout.tsx`，包含左侧 Sidebar（链接到 Dashboard, Users, CDK, Keys, Models, Playground）和顶部 Header。使用 shadcn 组件。然后配置 react-router 路由，路径前缀为 `/wadminw`，并添加 `AdminGuard` 权限校验组件。"

**Step 3: 具体页面 (以用户管理为例)**

> "实现 `pages/admin/UserManager.tsx`。
> 1. 使用 `useQuery` 调用 `getUsers` 接口。
> 2. 使用 `@tanstack/react-table` 渲染用户列表，列包含 ID, Email, Level, Balance, Status, Actions。
> 3. Actions 列包含 '编辑' 和 '充值' 按钮。
> 4. 点击充值弹出 shadcn Dialog，包含金额输入框，提交调用 `updateBalance` 接口。
> 5. 使用 React Hook Form + Zod 处理表单验证。"
> 
> 

按照这个方案执行，你的管理员后台将具备极高的可维护性和专业度。
