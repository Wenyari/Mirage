# Mirage 项目文档

## 简介

**Mirage** 是一个基于 React + TypeScript 构建的 AI 模型管理平台，提供完整的模型服务管理、用户权限控制、CDK 兑换系统和 AI 对话/视频生成等功能。

## 项目特性

### 技术亮点

- ✅ **现代化技术栈**：React 19 + TypeScript + Vite
- ✅ **完善的类型系统**：TypeScript 全覆盖，编译时类型检查
- ✅ **优雅的状态管理**：Zustand + TanStack Query 组合
- ✅ **组件化开发**：基于 Radix UI 构建，支持自定义主题
- ✅ **原子化 CSS**：Tailwind CSS，开发效率高
- ✅ **Mock 数据支持**：MSW 无需后端即可开发
- ✅ **代码质量保障**：ESLint + Prettier + TypeScript

### 功能特性

- 🎯 **双端设计**：管理后台 + 用户前台
- 🔐 **JWT 认证**：安全的用户认证机制
- 📊 **数据可视化**：Recharts 图表展示
- 💳 **CDK 系统**：兑换码生成和管理
- 🤖 **AI 功能**：对话聊天 + 视频生成
- 📱 **响应式设计**：支持多种设备

## 开始使用

### 5 分钟快速开始

```bash
# 1. 克隆项目
git clone <仓库地址>
cd frontend

# 2. 安装依赖
npm install

# 3. 启动开发服务器
npm run dev

# 4. 访问应用
# 用户前台: http://localhost:5173/
# 管理后台: http://localhost:5173/wadminw
```

**详细步骤**：请参阅 [快速开始](./02-快速开始.md)
