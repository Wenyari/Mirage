# 充值与兑换（用户端）

本页面为用户端的“充值与兑换”功能入口，路由为：`/setting/credits`。

页面功能概览：
- 左侧为设置导航（可扩展）；右侧为充值与卡密兑换区域与最近交易记录展示。
- 用户可以在“卡密兑换”输入框中输入 CDK 码并提交到后端接口 `POST /api/wallet/redeem`。
- 成功后，后端返回 `{"added_points": number, "current_balance": number}`，前端显示成功提示并刷新交易记录。

接口说明（前端示例调用）：

```javascript
// 兑换 CDK
await fetch('/api/wallet/redeem', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'Authorization': `Bearer ${token}`
  },
  body: JSON.stringify({ code: 'CDK-XXXX-YYYY' })
});
```

交易记录接口（用于页面加载最近交易）：

```
GET /api/wallet/transactions?page=1&size=20
Header: Authorization: Bearer <token>
```

注：页面在无交易记录时会显示“暂无交易记录”的占位文案。
